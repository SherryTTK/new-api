# 按密钥记录最新问答

仅超级管理员可在默认主题的「API 密钥 → 新增/编辑」中看到「记录最新问答」和「固定回复」配置。普通用户和普通管理员无法通过页面或 API 查看、设置这两个功能；普通密钥编辑不会清除已有的特权配置。查看记录仍需遵守原有密钥归属校验。

开启「记录最新问答」并保存后，系统保留该密钥最新一次进入文本转发处理流程的请求：

- 问题：请求中最后一条用户消息的文本；Completions 使用 prompt，Responses 使用 input。不会复制 system 指令或整个历史对话。
- 回答：实际发送给客户端的回答文本，不记录推理过程、媒体二进制或工具参数。多个候选回答取第一个；没有文本的请求或回答显示「无文本内容」。
- 附加信息：请求模型、开始时间和进行中/已完成/失败/已取消状态。

支持 Chat Completions、Completions、Responses、Claude Messages 和 Gemini 文本生成，涵盖流式、非流式、普通转发和固定回复。鉴权、渠道选择或请求校验阶段被拒绝的请求不会替换记录。

编辑页面每 5 秒自动刷新，也可手动刷新。可以分别复制问题、回答，或者一键复制完整问答。流式回答在请求结束后保存，进行中显示状态。关闭开关会停止记录后续请求，已有记录保留，已开始的记录可以继续完成。

每个密钥仅保存一条记录，并按请求开始时间排序。较早请求即使较晚完成，也不能覆盖更新请求的记录。内容存储在独立数据库表，不进入令牌鉴权缓存或密钥列表响应。数据库写入失败不会阻断原有模型响应。

问题和回答各最多保留 60,000 个 UTF-8 字节；超限时标记截断。单个响应 JSON / SSE 事件的解析缓冲上限为 1 MiB，超过时跳过无法完整解析的部分并标记截断，不影响实际下发给客户端的内容。

## API

仅超级管理员可通过令牌创建/编辑接口提交：

```json
{
  "record_last_request": true
}
```

省略或传 null 保留原配置，传 false 关闭。最新记录读取接口为 `GET /api/token/:id/last-request`，需要超级管理员登录并拥有该密钥，响应禁用 HTTP 缓存。无记录时 data 为 null。

数据库迁移会自动增加 `tokens.record_last_request` 和 `token_last_requests` 表；SQLite、MySQL 和 PostgreSQL 均使用 GORM 通用操作。
